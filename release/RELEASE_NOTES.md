# Per-Gamemode Glow v1.1.0

Первый публичный релиз мода для **Geometry Dash 2.2081** и **Geode 5.11.2**.

## Что внутри

- Встроенный редактор свечения: **F4** в меню или кнопка **GLOW** на экране паузы.
- Отдельные настройки для каждого режима: **cube, ship, ball, UFO, wave, robot, spider, swing**.
- Для каждого режима: цвет, яркость, пульсация и режим смешивания (Normal / Additive).
- Вкладки **Rainbow**, **Global** и **Presets**.
- Пресеты: создание, переключение, перезапись и удаление.
- RGB-режим с настройкой скорости, насыщенности и яркости.
- JSON-конфиг с live reload и горячие клавиши.
- Яркость **0–2**: `0–1` меняет прозрачность, `1–2` усиливает оттенок и свечение.
- Все кнопки редактора фиксированного размера, выровнены, вкладки полностью внутри сайдбара.

## Установка

1. Установите [Geode](https://geode-sdk.org/) **5.11.2** для Geometry Dash **2.2081**.
2. Скопируйте `zam.per-gamemode-glow.geode` в папку:
   `...\Geometry Dash\geode\mods\`
3. Запустите игру. Мод загрузится автоматически.

## Требования

- Windows
- Geometry Dash **2.2081**
- Geode **5.11.2**

## Известное ограничение

У **robot** и **spider** игра рисует контур свечения сама и берёт его цвет из свечения в наборе иконок.
Поэтому персональный цвет из конфига для этих двух режимов не применяется к контуру. У spider
дополнительно окрашивается зрачок, поэтому его цвет видно. Подробности — в `README.md`.
