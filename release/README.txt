Per-Gamemode Glow v1.1.0
Geometry Dash 2.2081 / Geode 5.11.2

Install:
1. Install Geode 5.11.2 for Geometry Dash 2.2081.
2. Copy zam.per-gamemode-glow.geode into:
   ...\Geometry Dash\geode\mods\
3. Start the game.

Open the editor with F4, or the GLOW button on the pause screen.
