# Per-Gamemode Glow

Отдельное свечение (glow) для каждого игрового режима в Geometry Dash: **cube, ship, ball, UFO, wave, robot, spider, swing**.

В ваниле GD есть один общий цвет свечения и один общий переключатель «Glow» — он одинаково применяется ко всем режимам. Этот мод оставляет игровые спрайты свечения как есть и переопределяет только их параметры (цвет, прозрачность, режим смешивания) для конкретного режима, пока этот режим отрисовывается.

Настраивать можно **прямо в игре**: нажмите **F4** в любом меню или **GLOW** на экране паузы — откроется редактор с вкладкой на каждый режим, выбором цвета, слайдерами яркости/пульсации и переключателем blending. Всё применяется сразу, без перезапуска уровня. Те же значения можно править и вручную в JSON-файле.

Мод **чисто клиентский**: он ничего не отправляет на сервер, не меняет прохождение уровней и не влияет на других игроков.

> Собрано под **GD 2.2081** и Geode **5.11.2** (нативная поддержка версии, без forward-compat).
>
> Репозиторий: https://github.com/ZAMWIN/GlowModes_2081

---

## Установка

1. Установите [Geode](https://geode-sdk.org/) для вашей версии GD (2.2081).
2. Положите `zam.per-gamemode-glow.geode` в папку `mods` рядом с игрой:
   `...\steamapps\common\Geometry Dash\geode\mods\`
3. Запустите игру — мод загрузится сам.

## Редактор в игре (GUI)

Открывается клавишей **F4** (настраивается в `hotkeys` → `open-menu`) или кнопкой **GLOW** справа
на экране паузы. Окно не блокирует игру: уровень продолжает идти, а изменения видны на следующем
кадре.

| Вкладка | Что настраивается |
|---------|-------------------|
| **Cube / Ship / Ball / UFO / Wave / Robot / Spider / Swing** | `Enabled`, цвет (встроенный цветовой пикер GD), `Brightness` (0–2), `Pulse` (0–5 с), `Blending` (Normal / Additive). |
| **Rainbow** | Включение перелива, скорость (0–0.5 об/с), насыщенность, яркость, blending. |
| **Global** | Общий выключатель мода, «уважать игровой переключатель Glow», время сглаживания цвета (`Fade`), запись debug-лога. |
| **Presets** | Список пресетов: `Prev`/`Next`, `Use custom colours`, имя нового пресета, `Save preset`, `Delete`. |

- Кнопка **Save** пишет JSON. **Reload** перечитывает файл с диска. Если закрыть окно с
  несохранёнными изменениями, они сохранятся автоматически.
- **Brightness** — не просто прозрачность: `0…1` плавно меняет непрозрачность, а `1…2`
  дополнительно подкрашивает и слегка увеличивает свечение. Поэтому верхняя половина слайдера
  тоже заметна.
- На вкладке **Presets** введите имя и нажмите **Save preset**: текущие цвета всех режимов
  сохранятся в пресет (если имя уже есть — пресет перезапишется) и сразу запишутся в JSON.
  `Prev`/`Next` листают пресеты, `Use custom colours` возвращает цвета из профилей режимов.
- Кнопки режимов слева подкрашены текущим цветом режима — так видно всю палитру сразу.
- У `Robot` и `Spider` вкладка показывает жёлтое предупреждение: GD рисует свечение этих двух
  режимов сам и может игнорировать цвет мода (см. «Ограничения»).
- Горячие клавиши продолжают работать и при открытом окне.

## Файл конфигурации

При первом запуске мод создаёт файл:

```
<папка сохранений Geode>/config/zam.per-gamemode-glow/per_gamemode_glow.json
```

Обычно это:

```
<папка игры>\geode\config\zam.per-gamemode-glow\per_gamemode_glow.json
```

Файл **перечитывается на лету**: как только вы сохранили его на диске, мод подхватывает
изменения в течение ~полсекунды (перезапуск не нужен). Правки возвращают значения из файла —
включая пресеты и ручные подстройки оттенка/яркости. Принудительно перечитать файл можно
горячей клавишей (по умолчанию `F5`).

### Структура

Файл — один JSON-объект: 8 ключей-режимов плюс несколько служебных (`debug`, `fade`, `preset`,
`hotkeys`, `presets`, `rgb`). По умолчанию **все режимы выключены** (`enabled: false`), то есть
мод ничего не делает, пока вы его не настроите. Отдельно есть RGB-режим (перелив по всем цветам,
см. раздел «RGB-режим»), который включается горячей клавишей и работает даже при выключенных
режимах.

```json
{
    "debug": false,
    "fade": 0.4,
    "preset": "",

    "hotkeys": {
        "enabled": true,
        "reload": "F5",
        "preset-next": "F6",
        "preset-prev": "F7",
        "hue-down": "F8",
        "hue-up": "F9",
        "brightness-down": "F10",
        "brightness-up": "F11",
        "rgb-toggle": "F12"
    },

    "presets": [],

    "rgb": {
        "enabled": false,
        "speed": 0.02,
        "saturation": 1.0,
        "brightness": 1.0,
        "blending": "normal"
    },

    "cube": {
        "enabled": false,
        "color": "#FFFFFF",
        "brightness": 1.0,
        "blending": "normal",
        "pulse": 0.0
    },
    "ship": { "...": "..." },
    "ball": { "...": "..." },
    "ufo":  { "...": "..." },
    "wave": { "...": "..." },
    "robot": { "...": "..." },
    "spider": { "...": "..." },
    "swing": { "...": "..." }
}
```

Ключи режимов: `cube`, `ship`, `ball`, `ufo`, `wave`, `robot`, `spider`, `swing`.

Служебные ключи верхнего уровня:

| Ключ      | Тип    | По умолчанию | Что делает |
|-----------|--------|--------------|------------|
| `debug`   | bool   | `false`      | Подробный лог: раз в секунду пишет в `geode/logs`, какой цвет/яркость/blend применён и что было в спрайтах до этого. Для `robot`/`spider` дополнительно выводит разбор их спрайтов (свечение, тело, конечности, дочерние узлы) — именно так и выяснилось ограничение из раздела «Ограничения». |
| `fade`    | number | `0.4`        | Плавность **любого** изменения цвета, в секундах: новый цвет не ставится сразу, а подтягивается к цели за это время. `0` — ставить сразу (резко). |
| `preset`  | string | `""`         | Имя пресета, который включён при загрузке. Пустая строка — использовать цвета режимов из этого файла. |
| `hotkeys` | object | см. ниже     | Горячие клавиши (см. раздел «Горячие клавиши»). |
| `presets` | array  | `[]`         | Именованные наборы цветов по режимам (см. раздел «Пресеты»). |
| `rgb`     | object | см. ниже     | Перелив по всем цветам (см. раздел «RGB-режим»). |

Если ключ режима отсутствует в файле или в нём стоит `enabled: false`, свечение этого режима **остаётся полностью ванильным** — мод к нему не прикасается.

### Параметры (для каждого режима)

| Параметр     | Тип    | По умолчанию | Что делает |
|--------------|--------|--------------|------------|
| `enabled`    | bool   | `false`      | Включить переопределение свечения для этого режима. |
| `color`      | string | `#FFFFFF`    | Цвет свечения. Форматы: `#RRGGBB`, `RRGGBB`, `#RGB`, `RGB`. Некорректное значение игнорируется (остаётся цвет по умолчанию) и пишется предупреждение в лог. |
| `brightness` | number | `1.0`        | Яркость свечения, `0.0 … 2.0`. `0…1` — непрозрачность спрайта, `1…2` дополнительно осветляет цвет и немного увеличивает свечение, поэтому диапазон выше `1.0` тоже работает. `0.0` делает свечение невидимым, но не выключает его. |
| `blending`   | string или bool | `"normal"` | Режим смешивания. `"normal"` / `"alpha"` / `"none"` / `false` — обычное альфа-смешивание. `"additive"` / `"add"` / `"blend"` / `"blending"` / `true` — аддитивное (свечение «складывается» с фоном и выглядит ярче). |
| `pulse`      | number | `0.0`        | Период пульсации в секундах: непрозрачность плавно ходит от 0 до значения `brightness`. `<= 0` — пульсация выключена ( ровное свечение). |

### Пример: разные цвета на каждый режим

```json
{
    "cube":   { "enabled": true, "color": "#FF3366", "brightness": 1.0, "blending": "normal",   "pulse": 0.0 },
    "ship":   { "enabled": true, "color": "#33AAFF", "brightness": 1.0, "blending": "normal",   "pulse": 0.0 },
    "ball":   { "enabled": true, "color": "#FFD700", "brightness": 0.9, "blending": "normal",   "pulse": 0.0 },
    "ufo":    { "enabled": true, "color": "#66FF99", "brightness": 1.0, "blending": "normal",   "pulse": 0.0 },
    "wave":   { "enabled": true, "color": "#CC66FF", "brightness": 1.0, "blending": "additive", "pulse": 0.0 },
    "robot":  { "enabled": true, "color": "#FF8800", "brightness": 1.0, "blending": "additive", "pulse": 2.0 },
    "spider": { "enabled": true, "color": "#00FFCC", "brightness": 1.0, "blending": "normal",   "pulse": 0.0 },
    "swing":  { "enabled": true, "color": "#FFFFFF", "brightness": 1.0, "blending": "additive", "pulse": 1.5 }
}
```

## RGB-режим (перелив по всем цветам)

Отдельный блок настроек: включённый RGB-режим **перекрывает все режимы сразу** — свечение плавно
идёт по всему цветовому кругу (красный → жёлтый → зелёный → голубой → синий → фиолетовый → …).
Включается/выключается горячей клавишей (`rgb-toggle`, по умолчанию `F12`) или ключом
`"enabled": true` в блоке `rgb`. Работает даже при выключенных режимах (`enabled: false`), так
что на свежей установке достаточно нажать `F12`.

```json
"rgb": {
    "enabled": false,
    "speed": 0.02,
    "saturation": 1.0,
    "brightness": 1.0,
    "blending": "normal"
}
```

| Параметр     | Тип    | По умолчанию | Что делает |
|--------------|--------|--------------|------------|
| `enabled`    | bool   | `false`      | Включён ли перелив при загрузке (дальше можно переключать клавишей). |
| `speed`      | number | `0.02`       | Скорость: сколько полных кругов по цветовому кругу в секунду. `0.02` — круг за 50 с, `0.04` — за 25 с, `0.1` — за 10 с, `0` — цвет замирает. |
| `saturation` | number | `1.0`        | Насыщенность. `1.0` — чистые яркие цвета, `0.6`–`0.8` — пастельные, `0` — белый. |
| `brightness` | number | `1.0`        | Яркость (множитель непрозрачности), `0.0 … 2.0`. |
| `blending`   | string или bool | `"normal"` | Режим смешивания, как у режимов. **Для перелива аддитивное не рекомендуется**: оно складывает цвет с фоном уровня, и по насыщенному фону колесо сжимается в пару оттенков (по синему фону красный читается фиолетовым, зелёный — бирюзовым). `"normal"` кладёт цвет сверху, и видны все цвета. |

Скорость удобнее всего подбирать горячими клавишами: `rgb-slower` (по умолчанию `PageUp`) и
`rgb-faster` (`PageDown`) ходят по круглым ступеням, а в лог пишется готовое значение:

```
Per-Gamemode Glow: RGB speed 0.04 turns/s = one full colour wheel in 25 s - put "speed": 0.04 in the "rgb" block to keep it
```

Ступени (`speed`, в скобках — время полного круга): `0.005` (200 с), `0.0075` (133 с), `0.01`
(100 с), `0.015` (67 с), `0.02` (50 с), `0.025` (40 с), `0.03` (33 с), `0.04` (25 с), `0.05`
(20 с), `0.06` (17 с), `0.08` (13 с), `0.1` (10 с), `0.13` (8 с), `0.16` (6 с), `0.2` (5 с),
`0.25` (4 с), `0.3` (3 с), `0.4` (2.5 с), `0.5` (2 с).

Ещё про поведение:

- Ни одно изменение цвета не «щёлкает»: новый цвет подтягивается за `fade` секунд (ключ `fade`),
  поэтому включение/выключение RGB и смена режима — плавный переход, а не мгновенная подмена.
- Фаза колеса считается по часам мода, а не по таймеру игрока: респавн или перезапуск уровня не
  сбрасывают цвет в красный.
- `hue-down`/`hue-up` (F8/F9) сдвигают фазу перелива для текущего режима, а
  `brightness-down`/`brightness-up` (F10/F11) — его яркость.
- Пресеты (`preset-next`/`preset-prev`) при включённом RGB ни на что не влияют: цвет берётся из
  колеса.
- На `robot` и `spider` контур свечения рисует сама игра (см. «Ограничения»), но у паука цвет
  всё же видно — мод красит зрачок глаза.

## Горячие клавиши

Настраиваются в блоке `"hotkeys"` того же файла. Работают **во время игры** (в уровне) и не
забирают нажатия у игры — клавиша уходит в игру как обычно, мод только считывает её.

| Клавиша в конфиге | По умолчанию | Что делает |
|-------------------|--------------|------------|
| `reload`          | `F5`         | Перечитать JSON-файл прямо сейчас. |
| `preset-next`     | `F6`         | Следующий пресет (по кругу). |
| `preset-prev`     | `F7`         | Предыдущий пресет (по кругу). |
| `hue-down`        | `F8`         | Сдвинуть оттенок **текущего режима** на −15°. |
| `hue-up`          | `F9`         | Сдвинуть оттенок текущего режима на +15°. |
| `brightness-down` | `F10`        | Уменьшить яркость текущего режима на 0.1. |
| `brightness-up`   | `F11`        | Увеличить яркость текущего режима на 0.1. |
| `rgb-toggle`      | `F12`        | Включить/выключить RGB-режим (перелив по всем цветам). |
| `rgb-slower`      | `PageUp`     | Перелив медленнее (на круглую ступень, см. «RGB-режим»). |
| `rgb-faster`      | `PageDown`   | Перелив быстрее. |
| `open-menu`       | `F4`         | Открыть/закрыть редактор (GUI). |

- `"enabled": false` в блоке `hotkeys` полностью отключает горячие клавиши (хук остаётся, но
  ничего не делает).
- «Текущий режим» — это режим, в котором игрок находится (или последний, в котором был). То
  есть `hue-up` в режиме корабля меняет только свечение корабля.
- Ручные подстройки оттенка и яркости **не записываются в файл** — это временные значения «на
  поиграть». Как только вы сохраните файл (или нажмёте `reload`), они сбросятся к значениям из
  файла. Чтобы сохранить понравившееся значение, впишите его в файл вручную.
- Каждое нажатие пишет строку в лог (`geode/logs`), например:
  `Per-Gamemode Glow: 'ship' hue -15 deg -> #FF6600`. Это позволяет подобрать значение логом,
  не заходя в файл.

### Как записать клавишу

Значение — строка. Понимаются:

- `F1` … `F24`;
- буквы `A` … `Z` и цифры `0` … `9` (например `"G"`, `"5"`);
- имена: `space`, `enter`, `tab`, `escape`/`esc`, `backspace`, `shift`, `ctrl`/`control`, `alt`,
  `capslock`, `pause`, `insert`, `delete`/`del`, `home`, `end`, `pageup`, `pagedown`,
  `up`, `down`, `left`, `right`, `numlock`, `scrolllock`;
- числовой код клавиши, если нужной нет в списке: `"0x42"` или `"66"` (так же, как в
  списке клавиш Geode);
- `none` / `off` / `"пусто"` — «клавиша не назначена».

Например, чтобы перезагрузка была на `F1`, а смена пресета — на `G`:

```json
"hotkeys": {
    "enabled": true,
    "reload": "F1",
    "preset-next": "G",
    "preset-prev": "H"
}
```

> Клавиши из `hotkeys` мод **не проверяет** на конфликты с биндами игры: если назначить `space`,
> мод будет реагировать на каждое нажатие пробела (игра — тоже, нажатие не съедается). По
> умолчанию выбраны `F5`…`F11`, которые в GD не заняты.

## Пресеты

Пресет — это именованный набор цветов по режимам. Полезен, чтобы быстро сравнить палитры или
настроить все режимы разом. Пресет **перекрывает только цвета**; `brightness`, `blending` и
`pulse` всегда берутся из профиля режима.

```json
"presets": [
    {
        "name": "Ice",
        "colors": {
            "cube": "#00FFFF", "ship": "#00FFFF", "ball": "#00FFFF", "ufo": "#00FFFF",
            "wave": "#00FFFF", "robot": "#00FFFF", "spider": "#00FFFF", "swing": "#00FFFF"
        }
    },
    {
        "name": "Lava",
        "colors": { "cube": "#FF4400", "ship": "#FF4400", "ball": "#FF4400" }
    }
]
```

- В `colors` можно указывать не все режимы: отсутствующие возьмут цвет из своего профиля.
- Пресеты можно создавать и удалять прямо в редакторе (**Presets**): введите имя, нажмите
  **Save preset**, и текущие цвета всех режимов попадут в JSON. Если имя уже существует, пресет
  перезаписывается.
- Переключение пресета — клавишами `preset-next` / `preset-prev` (`F6` / `F7` по умолчанию) или
  кнопками `Prev`/`Next` в редакторе. Активный пресет записывается в `"preset"` при сохранении
  окна, поэтому он включится сразу при следующем запуске.
- Чтобы вернуться к цветам из профилей режимов, нажмите **Use custom colours** (или поставьте
  `"preset": ""` и перечитайте файл).

## Настройки мода (кнопка настроек в Geode)

| Настройка | По умолчанию | Значение |
|-----------|--------------|----------|
| **Enabled** | вкл. | Общий выключатель. Когда выключен, мод не делает ничего и свечение полностью ванильное. |
| **Respect in-game glow toggle** | вкл. | Когда включено (рекомендуется), мод переопределяет свечение только тогда, когда в игре включена опция «Glow» в наборе иконок. Если выключить эту настройку, свечение мода будет работать даже при выключенном игровом Glow. |

> В Geode 5.11.2 под GD 2.2081 экран настроек Geode доступен, поэтому эти два переключателя
> видны и там, и на вкладке **Global** в редакторе мода.

### Как полностью отключить мод

Любой из способов:

1. Выключить настройку **Enabled** в настройках мода, либо
2. Поставить `"enabled": false` всем режимам в `per_gamemode_glow.json`, либо
3. Удалить/отключить сам мод в списке модов Geode.

## Как это работает (кратко)

Мод перехватывает `PlayerObject::update(float)` и `PlayerObject::updatePlayerArt()`. Каждый кадр он смотрит, в каком режиме находится игрок, берёт профиль этого режима из конфига и применяет цвет/прозрачность/blend к спрайтам свечения **именно этого** `PlayerObject` (`m_iconGlow` и `m_vehicleGlow`).

Для горячих клавиш мод перехватывает `cocos2d::CCKeyboardDispatcher::dispatchKeyboardMSG`, но
**только читает** нажатие: оригинальная функция вызывается всегда, с тем же результатом, поэтому
ввод (в том числе текстовые поля) работает как обычно.

Глобальные значения игры (`GameManager::m_playerGlowColor` и т.п.) **не изменяются** — поэтому настройки одного режима не «протекают» в другие: при смене режима следующему игроку просто применяется его собственный профиль. Применение повторяется каждый кадр и сразу после смены арта, так что чужие записи в спрайт свечения перекрываются и не мерцают.

## Ограничения и известные особенности

- **Robot и Spider: цвет из конфига там не появится — это ограничение самой игры.** У этих двух режимов GD рисует свечение-контур сама, своим проходом, и берёт цвет **из цвета свечения в наборе иконок**. Персональный цвет свечения игрока (именно его выставляет мод) игра для robot/spider игнорирует. Поэтому контур остаётся цвета вашего иконного Glow — например белым, если Glow белый, — сколько бы вы ни меняли `robot`/`spider` в конфиге. Это проверено дампом спрайтов: все видимые спрайты робота/паука несут цвета самой иконки, а оба спрайта свечения игра для этих режимов не рисует.
  Что всё-таки делает мод: красит спрайт свечения робота/паука (ничего не ломает, но на этом билде GD его не рисует) и пишет предупреждение в лог, если профиль `robot`/`spider` включён.
  **У паука цвет всё же видно** — мод красит зрачок глаза (`m_extraSprite`), так что паук в любом режиме (в том числе в RGB-переливе) светится выбранным цветом. Сначала это было случайным побочным эффектом, но оставлено намеренно: иначе у `spider` вообще не было бы никакого видимого эффекта.
  У робота такой детали нет: та же `m_extraSprite` у него скрыта (`m_hasExtra = 0`) либо это часть арта иконки, которую мод не перекрашивает.
  Если нужен другой цвет контура у робота/паука — меняйте **цвет свечения в наборе иконок** (это повлияет на все режимы) либо оставьте эти два профиля выключенными. Значение `pulse` для них тоже ни на что не влияет.
- **Jetpack (ракетный ранец).** Отдельного ключа для него нет: в GD 2.2081 юзер-объект не различает jetpack отдельным флагом `PlayerObject`. Настройте `ship` — jetpack использует корабль и его свечение.
- **Иконки в гараже (превью иконок).** Мод не влияет на превью в магазине иконок: там используются `SimplePlayer`, а не игровой `PlayerObject`.
- **Пульсация (`pulse`)** — это собственный таймер мода, он не синхронизирован с пульсацией от триггеров уровня. Если уровень сам меняет цвет свечения, мод всё равно перекроет его своим значением (в этом и смысл мода).
- **Файл конфига читается на лету** (после сохранения изменения применяются за ~0.5 с), но
  ручные подстройки оттенка/яркости горячими клавишами в файл не пишутся и сбрасываются при
  перечитывании файла.
- Значения вне диапазонов (например, `brightness` больше 2) обрезаются до допустимых.

## Совместимость и конфликты

Мод правдоподобно сочетается с другими модами, меняющими свечение, потому что он не трогает глобальные переменные игры, а пишет напрямую в спрайты конкретного игрока:

- **Blending Glow** — совместим. Мод задаёт свой режим смешивания для спрайта свечения, поэтому для режимов с `enabled: true` действует значение из вашего конфига (его можно поставить в `"blending": "blending"`, чтобы получить поведение аддитивного свечения, как в Blending Glow). Для режимов с `enabled: false` работает Blending Glow как обычно.
- **Custom Gamemode Colors** — совместим: тот мод меняет цвета иконок/режимов, а Per-Gamemode Glow — только свечение. Мод читает игру после её изменений, так что цвет иконки останется от Custom Gamemode Colors, а свечение — от этого мода.
- **Separate Dual Icons** — совместим: мод применяет профиль к каждому `PlayerObject` отдельно, поэтому у второго игрока в дуэли свечение тоже будет по его текущему режиму, и настройки не смешиваются.
- **Моды, меняющие глобальный Glow игры** — учтены настройкой «Respect in-game glow toggle».

Если два мода пишут в один и тот же спрайт свечения в одном кадре, побеждает тот, кто сработал последним. Per-Gamemode Glow применяет значения в `update()` (то есть в конце кадра обновления игрока), поэтому обычно он оказывается последним; если эффект «перебивается» другим модом, отключите в этом моде соответствующий режим (`enabled: false`) или переключите один из модов.

## Сборка из исходников

Основная цель — **GD 2.2081** и релизный **Geode SDK 5.11.2** (тот же лоадер, который стоит у
пользователя). Для этой версии не нужны никакие шимы: SDK уже содержит правильные адреса и
заголовки, а `mod.json` объявляет `"gd": { "win": "2.2081" }`.

Что нужно:

- Visual Studio 2022+ (или Build Tools) с компонентом «Desktop development with C++» и Windows SDK;
- CMake 3.21+;
- Geode SDK 5.11.2 и переменная окружения `GEODE_SDK` на него;
- установленный Geometry Dash 2.2081.

```powershell
$env:GEODE_SDK = "<путь к SDK 5.11.2>"
cmake -B build-2081 -G "Visual Studio 17 2022" -A x64 -DGEODE_CLI="<путь к geode.exe>"
cmake --build build-2081 --config RelWithDebInfo --parallel 6
```

Готовый `.geode` появится в `build-2081/`.

> **Только GD 2.2081.** Мод использует нативный Geode 5.11.2 и не предназначен для 2.2091.
> Готовый файл для установки лежит в папке `release/`.
